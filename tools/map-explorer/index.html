Civ13 · unpublished review prototype

Explore authored maps

Compare four existing Nomads layouts and open their original layer images. These are static source renders: current hosting and player access are unverified.

Runtime lighting, generated objects, animation and lower-level view projection are absent. This browser does not connect to a game server or generate maps.

Images stay unloaded until you choose one. Opening a full-resolution layer can use substantial memory; the file size and dimensions are shown first.
